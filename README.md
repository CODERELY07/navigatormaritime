# Navigatormaritime

I Just Clone the Navigatormaritime Website.

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/CODERELY07/navigatormaritime.git
   cd yourproject
2. Set up the database
   Create a new MySQL database named 'navigatormaritime'.
   folder:
   sql/navigatormaritime.sql

   Configure the application
   Update your database credentials in connection/db.php 

3. Run the project

   Place the project folder in your web server’s root directory

   Start your web server.

   Open in your browser:
